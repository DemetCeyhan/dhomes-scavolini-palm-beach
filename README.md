# Dhomes Scavolini Palm Beach

D'homes markası Scavollinin'in amerikada palm beach bölgeisnde açılacak yeni bayisi. Aşağıda linklerini verdiğim sayfalardaki gibi detaylı bir web sitesi tasarlanacak. Sen bir senior UI UX designersın. sitede anasayfa (biz kimiz), ürünlerimiz (oturma odası, mutfak, banyo, yaşam alanları, masa ve sandalyeler ve outdoor), Randevu/form sistemi, dil çevirisi ingilizce ispanyolca ve italyancaya çevrilecek, projelerimiz (devam eden projeler, tamamlanmış projeler) olacak. sayfa ingilizce olacak. Renkler scavollinini kırmızı siyah beyaz havasında olmalı. sana ekte d'homes logosunu da iletiyorum. İncele ve bana belirttiğim içeriklerde 1440 px web 375 px mobil web sitesini tasarla. Yaratıcı ve sanatsal görünmeli, geçişlerde veya sayfada effeck, minimal animasyon vb kullanmalısın.
